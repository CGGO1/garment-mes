# 服装 MES 系统 — 部署文档

## 1. 环境要求

| 组件 | 版本要求 |
|---|---|
| JDK | 21 |
| Maven | 3.9.x（本机 3.9.14） |
| Node.js | ≥ 20（本机 22.22.2） |
| Docker | Docker Desktop（Windows） |

> 说明：本机 Git Bash 存在 MSYS 路径转换失效问题，导致 `mvn` 找不到 classworlds jar。已提供 `mvnw.sh` 脚本（项目根目录）修复，所有 Maven 命令请用 `../mvnw.sh` 替代 `mvn`。

## 2. 启动数据库

启动 Docker Desktop 后：

```bash
cd docker
docker compose up -d
```

- 镜像：`postgres:16-alpine`
- 宿主机端口：**5433**（容器内 5432）
- 库：`mes`　用户：`mes`　密码：`mes123456`
- 数据卷：`mes-postgres-data`（持久化）

验证：

```bash
docker exec mes-postgres pg_isready -U mes -d mes
```

## 3. 启动后端

```bash
cd mes-backend
../mvnw.sh spring-boot:run
```

或打包后运行：

```bash
../mvnw.sh clean package -DskipTests
java -jar target/mes-backend-1.0.0.jar
```

- 端口：**8080**
- 接口文档：http://localhost:8080/doc.html
- 启动时自动建表（schema.sql）+ 初始化管理员/菜单/字典（DataInitializer）

## 4. 启动前端

```bash
cd mes-frontend
npm install
npm run dev
```

- 开发端口：**5175**
- 访问：http://localhost:5175
- 默认账号：`admin` / `admin123`
- Vite 已配置 `/api` 代理到 `http://localhost:8080`

生产构建：

```bash
npm run build
# 产物在 dist/，可部署到 Nginx 并反代 /api 到后端
```

## 5. AI 能力配置

AI 报表与 AI 助手通过 HTTP 调用 Lili 知识库网关，编辑 `mes-backend/src/main/resources/application.yml`：

```yaml
mes:
  ai:
    lili-base-url: http://192.168.11.81:10000   # Lili 网关
    lili-token: ${MES_AI_LILI_TOKEN:}            # 认证 token（环境变量）
```

- 未配置 / Lili 离线时，AI 报表自动降级为本地统计报表，PDF/Excel 下载仍可用；
- AI 助手在 Lili 离线时返回「AI 服务未连接」提示。

## 6. 配置项说明

| 配置 | 默认值 | 说明 |
|---|---|---|
| `server.port` | 8080 | 后端端口 |
| `spring.datasource.url` | jdbc:postgresql://localhost:5433/mes | 数据库连接 |
| `mes.jwt.secret` | （默认值） | 生产环境用 `MES_JWT_SECRET` 覆盖 |
| `mes.jwt.expire-minutes` | 1440 | Token 有效期（分钟） |
| `mes.ai.lili-base-url` | http://192.168.11.81:10000 | Lili 网关地址 |
| `mes.wechat.app-id` | 空 | 微信公众号 appId，启用微信 JS-SDK 扫码（`MES_WECHAT_APP_ID`） |
| `mes.wechat.app-secret` | 空 | 微信公众号 appSecret（`MES_WECHAT_APP_SECRET`） |

## 6.1 微信扫码（JS-SDK）配置说明

- 系统生成的二维码为标准 QR 码，**微信「扫一扫」可直接识别**；
- 若希望**在微信内置浏览器中点击页面「扫码」按钮**调用微信扫码，需要：
  1. 准备一个已认证的微信公众号（服务号），在公众平台获取 `appId` / `appSecret`；
  2. 在「公众号设置 → 功能设置 → JS 接口安全域名」中添加 MES 部署域名；
  3. 部署域名必须为 **HTTPS**，且与用户访问 MES 的地址一致；
  4. 通过环境变量 `MES_WECHAT_APP_ID` / `MES_WECHAT_APP_SECRET` 配置后端后重启；
  5. 前端在微信内点击「扫码」会调用 `wx.scanQRCode`；未配置或签名失败时**自动降级为摄像头扫码 / 手动输入**，不影响原功能。

## 7. 常见问题

**Q：`mvn` 报「找不到 classworlds 主类」**
A：用 `mvnw.sh` 替代 `mvn`（已内置 Windows 路径转换修复）。

**Q：Docker 启动失败**
A：确认 Docker Desktop 已启动（daemon 运行中）。

**Q：前端启动失败（Node 版本冲突）**
A：确认使用 Node 22（WorkBuddy 托管路径），而非系统 Node 16。

**Q：登录后页面空白**
A：确认后端已启动、数据库已初始化；检查浏览器控制台网络请求。
