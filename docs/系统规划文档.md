# 服装制造业进出口贸易 MES 系统 — 系统规划文档

> 版本：V1.0　日期：2026-08-17

## 1. 项目概述

面向服装制造业进出口贸易企业，构建一套**独立部署**的制造执行系统（MES），覆盖从进出口订单、生产执行、库存到质量检验的核心业务链路，并通过 AI 能力（对接 Lili 知识库）提供智能报表与工艺问答。

### 1.1 建设目标

- 打通「订单 → 生产 → 库存 → 质检」核心业务闭环；
- 提供进出口贸易专属能力（贸易术语 Incoterms、HS 编码、单证、出货）；
- 内置 **AI 即席报表**：根据页面数据自动生成一次性报表，可下载 PDF/Excel；
- 内置 **AI 助手**：工艺问答、单证理解、合规检索；
- 采用开源技术栈、模块化单体架构，易于维护与后续演进。

### 1.2 设计原则

- **独立部署**：不与现有 ERP（SQL Server）耦合，独立 PostgreSQL 数据库；
- **模块化单体**：单 Spring Boot 应用，内部按业务域分包，预留微服务拆分边界；
- **AI 能力外置**：AI 通过 HTTP 调用 Lili 知识库，不引入 Milvus/ES 等重中间件；
- **数据真实准确**：杜绝占位符，命名统一 snake_case。

## 2. 功能模块规划

### 2.1 系统管理（system）
用户管理、角色管理、菜单管理（RBAC 动态菜单）、字典管理（贸易术语、AQL 等级等）。

### 2.2 主数据（master）
- 客户、供应商
- 产品/款式（款号、HS 编码 61/62 章、成分、克重 GSM、门幅）
- 物料（面料 / 辅料：拉链、纽扣、标签）
- 工序（裁剪、车缝、后整、包装，含工价）

### 2.3 进出口贸易（trade）
- 出口/进口订单（头 + 明细）
- 贸易术语 Incoterms（EXW/FOB/CIF 等）、币种、交期
- 订单状态流转：草稿 → 待生产 → 生产中 → 质检中 → 已出货 → 已完成
- 单证管理（商业发票、装箱单、提单、原产地证）、出货计划

### 2.4 生产管理（production）
- 生产工单（头 + 工序明细）
- 工序进度与报工（扫码/条码录入产量）
- 裁床记录（批次、扎号、裁出量、条码）

### 2.5 库存管理（inventory）
- 仓库、入库单、出库单
- 现存量、库存流水（入库/出库自动更新库存并记录流水）

### 2.6 质量管理（quality）
- 质检标准（AQL 验货等级 1.0/1.5/2.5/4.0）
- 验货单（IQC 来料 / IPQC 过程 / FQC 成品 / OQC 出货 / QA 出货）
- 检验项目、疵点记录

### 2.7 AI 能力（ai + report）
- **AI 即席报表**：选择数据模块 + 描述需求 → 自动生成报表 → 预览 → 下载 PDF/Excel
- **AI 助手**：工艺问答、单证理解、合规检索（后端代理到 Lili）

### 2.8 规划中的扩展模块（后续阶段）
- 生产计划与排产（APS、甘特图、产能评估）
- 样品开发管理
- 设备管理（EAM：台账、点检、保养、维修）
- 外发加工管理、批次全程追溯
- 数据大屏看板

## 3. 架构设计

### 3.1 总体架构

```
浏览器（Vue 3 + Element Plus SPA）
        │ axios (JWT Bearer)
        ▼
mes-backend（Spring Boot 3.5 单体 :8080）
  ├── 表现层 controller（各业务域）
  ├── 业务层 mapper（MyBatis-Plus）
  ├── 安全层 Spring Security + JWT
  ├── report 模块（AI 即席报表 + PDF/Excel 导出）
  └── ai 客户端（HTTP 调用 Lili 网关 RAG/LLM 接口）
        │                        │
        ▼                        ▼
PostgreSQL 16             Lili 知识库网关（:10000）
```

### 3.2 技术选型

| 层 | 技术 | 版本 |
|---|---|---|
| 前端框架 | Vue 3 + Vite + TypeScript | 3.5 / 6.x |
| UI 组件库 | Element Plus | 2.14 |
| 状态/路由 | Pinia + Vue Router | 3.x / 4.x |
| 图表 | ECharts | 6.x |
| 后端框架 | Spring Boot（WebMVC） | 3.5.0 |
| 语言 | Java | 21 |
| ORM | MyBatis-Plus | 3.5.15 |
| 数据库 | PostgreSQL | 16 |
| 认证 | Spring Security + jjwt | 0.12.6 |
| 文档 | knife4j + springdoc | 4.5.0 |
| Excel | EasyExcel | 3.3.4 |
| PDF | openhtmltopdf | 1.0.10 |

### 3.3 命名与分层约定

- 数据库表/列：snake_case（`sys_user`、`trd_order_item`）
- Java 字段：camelCase，`@TableName`/`@TableId` 显式映射
- 通用审计字段：`BaseEntity`（create_by/create_time/update_by/update_time/is_delete 逻辑删除）
- 后端分包：`common` / `config` / 各业务域（`system`/`master`/`trade`/`production`/`inventory`/`quality`/`report`/`ai`）

## 4. AI 即席报表设计

### 4.1 交互流程

```
用户点击「AI 报表」→ 选择数据模块 + 描述需求
  → 后端查询模块数据 → 调用 Lili LLM 生成报表 JSON
  → 返回结构化报表（标题/摘要/分析/图表/表格）
  → 前端预览（ECharts 图表 + 表格 + 文本）
  → 下载 PDF / Excel
```

### 4.2 降级策略

LLM 未配置或调用失败时，自动**降级为本地统计报表**（基于数据的表格 + 状态分布图 + 说明文字），确保报表与下载功能始终可用。
