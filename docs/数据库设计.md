# 服装 MES 系统 — 数据库设计

> 数据库：PostgreSQL 16　命名约定：snake_case 表/列，主键 VARCHAR(32) 雪花ID，逻辑删除 is_delete(N/Y)

## 1. 通用约定

- 所有表含审计字段：`create_by` / `create_time` / `update_by` / `update_time` / `is_delete`
- 主键：`@TableId(type = ASSIGN_ID)` 生成 19 位雪花 ID 字符串
- 逻辑删除：`@TableLogic(value="N", delval="Y")`
- Java 字段 camelCase ↔ 列 snake_case（MyBatis-Plus `map-underscore-to-camel-case`）

## 3. 核心表字段

### trd_order（订单）
| 字段 | 类型 | 说明 |
|---|---|---|
| order_id | VARCHAR(32) PK | 订单ID |
| order_no | VARCHAR(64) | 订单号 |
| order_type | VARCHAR(16) | EXPORT/IMPORT |
| customer_id | VARCHAR(32) | 客户 |
| incoterm | VARCHAR(16) | 贸易术语 |
| currency | VARCHAR(16) | 币种 |
| status | VARCHAR(32) | DRAFT/PENDING/IN_PRODUCTION/QC/SHIPPED/COMPLETED |
| total_amount | NUMERIC(18,2) | 总金额 |
| delivery_date | TIMESTAMP | 交期 |

### prd_work_order（工单）
| 字段 | 类型 | 说明 |
|---|---|---|
| work_order_id | VARCHAR(32) PK | 工单ID |
| work_order_no | VARCHAR(64) | 工单号 |
| product_id | VARCHAR(32) | 产品 |
| plan_qty / finish_qty | NUMERIC(12,2) | 计划/完成数 |
| status | VARCHAR(32) | PLANNED/IN_PRODUCTION/COMPLETED |

### qc_inspection（验货单）
| 字段 | 类型 | 说明 |
|---|---|---|
| inspection_id | VARCHAR(32) PK | 验货单ID |
| inspection_no | VARCHAR(64) | 验货单号 |
| inspection_type | VARCHAR(32) | IQC/IPQC/FQC/OQC/QA |
| standard_id | VARCHAR(32) | 质检标准 |
| sample_qty / pass_qty / fail_qty | NUMERIC(12,2) | 抽样/合格/不合格 |
| result | VARCHAR(32) | PENDING/PASS/FAIL |

## 4. 建表脚本

全量建表脚本位于 `mes-backend/sql/schema.sql`，后端启动时通过 `spring.sql.init` 自动执行（幂等，`CREATE TABLE IF NOT EXISTS`）。初始化数据（管理员、角色、菜单、字典）由 `DataInitializer` 在启动时自动写入。
